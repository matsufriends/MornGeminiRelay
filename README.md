# MornGeminiRelay

Gemini の質問・回答・生成コードを Slack のスレッドに転送する Chrome 拡張。質問履歴の Markdown 保存にも対応。

## セットアップ

1. `chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ。
2. Slack App に `chat:write`・`files:write`・`chat:write.customize` を付与し、ワークスペースへインストールする。権限を追加した場合は再インストールする。
3. 投稿先チャンネルで `/invite @<App名>` を実行する。
4. 拡張の設定に Bot Token・チャンネル ID・任意の表示名を入力し、転送への同意にチェックして保存する。Gemini にログインして使う。

## 使い方

- **自動転送**：Gemini へ送信すると同じ会話のスレッドへ投稿。ユーザーは 👤、Gemini は 🤖、コード・Canvas の添付は 📎 で表示する。
- **過去の会話を転送**：「全チャットを取得」→ 会話を選択 →「送信」。新しいスレッドを作り、以後の自動転送もそこへ送る。
- **質問履歴を保存**：「Gemini を開いて履歴を保存」。自分の質問のみを、会話ごとの `.md` としてダウンロードする。

一括転送・保存の専用タブは完了まで操作しない。Canvas は取得できた HTML のみを添付し、更新を検知すると再添付する。Gemini の画面変更や読み込み状況によって取得できない場合がある。

Bot Token・投稿先・表示名・スレッドの対応をブラウザ内に保存する。会話本文は拡張に永続保存しない。ユーザーが添付したファイルは名前だけを転送する。

開発時の確認：`node test.js`

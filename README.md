# MornGeminiRelay

Gemini (gemini.google.com) に投げた質問と回答を Slack のスレッドへ転送し、質問履歴を Markdown でダウンロードする Chrome 拡張。

## インストール

1. `chrome://extensions` → デベロッパーモード ON → 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ
2. Slack に転送する場合は Slack App を作り、以下を設定する
   - Bot Token Scopes に `chat:write` を追加してワークスペースにインストールし、Bot User OAuth Token (`xoxb-…`) を控える
   - 投稿先チャンネルで `/invite @<App 名>` を実行する (招待せずに公開チャンネルへ投稿するなら `chat:write.public` も追加)
   - チャンネル詳細の最下部にあるチャンネル ID (`C…`) を控える
3. 拡張機能に Bot Token とチャンネル ID を入力し、「保存」を押す

## 質問履歴を保存

どのページからでも「Gemini を開いて履歴を保存」を押すと、保存専用の Gemini タブを開き、会話一覧の取得から `.md` のダウンロードまで順に実行する。Gemini にログイン済みであることが必要。複数アカウントを使っている場合は、新しく開いた Gemini のアカウントが対象になる。

- 会話一覧を末尾までスクロールし、追加で読み込まれる会話も取得する。
- 各会話を開き、質問の描画と上方向への追加読み込みが落ち着いたら保存する。固定の 5 回スクロール待ちは行わない。
- `ダウンロード/gemini-history-<日付>/<会話タイトル>.md` に 1 会話 1 ファイルで出力する。対象は自分の質問のみで、Gemini の回答や送信日時は含まない。同じ質問を複数回送っていた場合も、そのまま残す。
- 完了まで保存専用タブを操作しない。タブを閉じると中止する。進捗や停止理由は拡張機能を開くと確認できる。
- ダウンロード成功を確認してから次の会話に進む。本文が取得できない場合や保存に失敗した場合は、黙って飛ばさず停止する。

Gemini の画面に読み込める会話が対象。DOM の更新停止を 800ms 待って進むため、Gemini 側の表示変更や、読み込み中表示を伴わない遅い応答では完全性を保証できない。取得速度も Gemini の読み込み時間に依存する。

## Slack 転送とデータ保存

送信操作後に Gemini の入力欄が空になったら、質問を Google アカウント名・メールとともに Slack へ転送する。新しい会話の最初の質問が親投稿になり、その会話の Gemini の回答と以降の質問はすべて親投稿のスレッドに返信する。回答は停止ボタンが消えて本文が 1.5 秒変わらなくなった時点で転送する。見出し・太字・番号付き/入れ子の箇条書き・インラインコードは Slack の書式に変換し、回答中のコードブロックは `📎 code-<n>.<拡張子>` の見出し付きで、同じスレッドにコードブロックとして投稿する (長いものは行単位で分割)。`files:write` スコープは使わない。Canvas のコードは本文の完了後も生成が続くため、本文の投稿後も最大 10 分その回答を見張り、プレビューに HTML が載った時点で `📎 canvas-<n>.html` として同じスレッドに追加投稿する。問い合わせは Gemini のページ側で動く `canvas-bridge.js` が送り (拡張機能側から直接送ると応答が返らなかったため)、HTML はプレビューのフレームで動く `preview.js` が返す (scf フレームが HTML を blob にする瞬間に控え、blob: に遷移したフレームでは自身を読み直す)。コードタブのエディタは見えている行しか描画しないので使わない。Gemini が HTML に差し込む `<script data-bard-client-injected>` (認証トークン・Firebase 設定入り) は取り除き、それでもトークンやキーの値が残っていれば送らない。履歴の一括保存では Slack に送信しない。

Incoming Webhook は投稿の `ts` を返さず親投稿のスレッドに返信できないため、Bot Token で `chat.postMessage` を使う。

拡張機能は質問本文を蓄積しない。永続保存するのは Bot Token・チャンネル ID と、会話 ID → 親投稿 `ts` の対応表のみ。作業中の会話 URL・タイトルと進捗だけを `chrome.storage.session` のメモリ上に保持し、本文は `.md` に直接出力する。タブを閉じると作業情報も削除する。旧版で保持していた質問履歴・取り込み情報・Discord Webhook URL は、更新後に拡張機能が起動すると削除する。
